Make it yours, down to the markup

01

Style it with your own CSS

Light and dark themes, colour and radius presets, or your own CSS on top. Built from Web Components, so it drops into any framework without adapters.

uc-file-uploader-regular {
  --uc-primary:
    oklch(0.89 0.13 90);
  --uc-radius: 4px;
  --uc-font-family:
    Inter, sans-serif;
}
02

Use your own interface

Trigger the uploader from your own button with initFlow(), or build a fully custom flow on the upload client library.

const api = document
  .querySelector(
    'uc-upload-ctx-provider'
  )
  .getAPI();

myButton.addEventListener(
  'click', () => {
    api.initFlow();
  });
03

Extend it with the Plugin API

Add custom upload sources, UI activities, file actions, and hooks as plugins. The uploader gains what you need without you forking it or waiting on us.

pluginApi.registry
  .registerSource({
    id: 'dam',
    label: 'dam.label',
    icon: 'folder',
    onSelect() {
      uploaderApi
        .setCurrentActivity(
          'dam'
        );
    },
  });

FAQ

What is Uploadcare File Uploader?
Uploadcare File Uploader is a drop-in upload widget for accepting files from your users. It ships as Web Components that run natively in React, Vue, Angular, Svelte and Next.js, accepts files up to 5 TB from local storage, camera, and cloud accounts, and can validate and scan every file before it reaches storage.
Which frameworks does it support?
The uploader is built from Web Components, so it runs natively in any modern JavaScript framework. Ready-made examples exist for React, Vue, Angular, Svelte, Next.js and plain JavaScript, with an optional React adapter for React and Next.js projects that prefer a React-first component API. Back-end SDKs cover JavaScript, PHP, Python, Ruby, Go, Java and Rust, and there are native integrations for iOS and Android.
Where can users upload from?
Local files, device camera, a direct link, Dropbox, Google Drive, Google Photos, OneDrive and more, all through the same interface. You choose which sources appear, per project.
What is the maximum file size?
Up to 5 TB. Large files are split into chunks and uploaded in parallel, going straight to storage rather than through Uploadcare’s upload servers.
Can I customize how it looks and behaves?
Yes. Light and dark themes, colour and radius presets, and your own CSS on top. Run it headless to trigger the flow from your own button, and use the Plugin API to add custom upload sources, UI activities, file actions, and hooks without forking the uploader.
How are uploads secured?
Files can be filtered by MIME type and size on upload, scanned for malware, and checked for unsafe content, with infected files blocked when you configure it that way. Signed uploads restrict who can upload and for how long, using HMAC-SHA256 signatures with an expiry. The uploader also blocks remote code execution through SVG, HTML and XML files.
Is Uploadcare SOC 2, HIPAA, and GDPR compliant?
Uploadcare is SOC 2 Type II audited and GDPR compliant, and HIPAA-ready workflows are available. The Upload API carries a 99.9% uptime SLA. Current certifications and documentation are in the Trust Center.
Is the uploader accessible?
Yes. Full keyboard navigation across the upload flow and the image editor, screen reader and voice assistant support, and current accessibility standards. Interface and validation text is localizable.
How does pricing work?
Uploadcare bills in operations rather than credits, drawn from a single monthly allowance that covers uploads, transformations, and delivery. New accounts start with a 14-day Pro trial. Full details are on the pricing page.
