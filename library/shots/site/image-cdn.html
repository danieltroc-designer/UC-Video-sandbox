Everything you can do to an image

Automatic optimization

Automatic format conversion

Save time with automatic conversion of images to modern formats like AVIF and WebP, and cache variations without taking up storage.

Adaptive image quality

Forget fine-tuning compression. Algorithms under the hood set quality per image, so a flat photograph loses more data than a detailed one without anyone noticing.

Fully automated responsive images

Serve images sized for each screen and resolution, from one stored file. The <uc-img> component handles the srcset attributes so you never write them by hand.

Content-aware editing

Smart resize

Retain the proportions of faces and crucial objects while automatically resizing the rest of the image and applying a matching color to fill in the missing background.

Smart crop

Detect and focus on faces and objects while cropping the background with content-aware algorithms. Combine with scale cropping to ensure distortion-free image galleries across devices on the fly.

Background removal

Isolate the subject and drop the background in one operation. Product listings come out uniform without anyone opening an image editor.

Image enhancements

Ensure all images are sharp and professional by adjusting brightness, gamma, contrast, and applying photo filters, using either simple URL parameters or AI-based algorithms.

Overlays and watermarks

Programmatically protect and customize images with text titles, copyright, descriptions, brand logos, or watermarks, without engaging the design team.

Face-detection transformations

Easily create user photos with automatic cropping, and ensure compliance with privacy laws by applying face blur at scale.

Object recognition

Labels with confidence scores for general objects and scenes, so a library can be tagged and filtered without training or hosting a classifier.

Control from the URL

URL-based transformations

Transform images in real time using a URL-based API and simple parameters, and serve those images directly from cache without reprocessing or altering the source file.

Chainable transformations

Stack multiple operations in a single URL string, applied in order, instead of running them through separate tools.

EXIF metadata removal

Strip location and camera data on delivery. User photos reach your visitors without carrying where they were taken.

FAQ

What is Uploadcare Image CDN?
Uploadcare Image CDN is a CDN for images that combines image hosting, optimization, transformation, and delivery in one service. It converts images to modern formats per browser, applies compression tuned to each image, and exposes 40+ operations as URL parameters. Transformed versions are generated on first request and cached at the edge, while your stored original stays untouched.
Which image formats can I upload and deliver?
Uploadcare accepts AVIF, BMP, GIF, HEIC, JPEG, PCX, PNG, TGA, TIFF, and WebP. SVG files work natively with geometric operations, and rasterizing them unlocks the full operation set. On delivery, format is chosen per request: AVIF or WebP where the browser supports them, otherwise PNG or JPEG depending on the image content. You store one original regardless of what each visitor receives.
How much smaller do images get?
It depends on the source image, since compression is set per image rather than per project. The savings come from two things together: converting to AVIF or WebP, and adapting quality to the content of each image. Shogun cut image bandwidth costs by 86% after moving to Uploadcare.
What image operations are available?
40+ operations, all applied from the URL. Resize, crop, and scale crop. Smart crop and smart resize, which detect faces and objects and crop around them. Rotate, flip, and mirror. Overlays, watermarks, and text. Color adjustment, photo filters, blur, and sharpen. Face blur, background removal, and object recognition. Operations can be chained in a single URL and apply in order.
Can I use it with images I already store somewhere else?
Yes. Prefix an existing image URL with your Uploadcare proxy endpoint and the source is fetched, processed, and cached at the edge. Your original file stays where it is, so existing references keep working and nothing has to move for you to start.
Is there a size limit on the images I can process?
Operations apply to files up to 100 MB and images up to 75 megapixels. Output dimensions go up to 3000x3000 pixels by default, or 5000x5000 when you set the format to JPEG. Both limits can be raised on request.
Is Uploadcare SOC 2, HIPAA, and GDPR compliant?
Uploadcare is SOC 2 Type II audited and GDPR compliant, and HIPAA-ready workflows are available. Malware scanning runs on every upload, unsafe content moderation is available, and signed URLs restrict access to private or paid images. Current certifications and documentation are in the Trust Center.
How does pricing work?
Uploadcare bills in operations rather than credits, drawn from a single monthly allowance that covers uploads, transformations, and delivery. There’s a free plan with no card required. Full details are on the pricing page.
